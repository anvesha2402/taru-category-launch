# TARU logo files

Fictional brand for an independent student portfolio project.

All marks are outlined vector paths (no fonts needed to open them). Canva, Figma and Illustrator all import SVG.

| File | Use |
|---|---|
| `taru_primary_{heartwood,reversed,ink}.svg` | Seal + wordmark, horizontal. Reversed = Kora on Heartwood |
| `taru_stacked_{heartwood,reversed,ink}.svg` | Seal above wordmark, for square formats |
| `taru_stacked_bilingual_heartwood.svg` | Stacked with तरु |
| `taru_wordmark_*.svg`, `taru_seal_*.svg` | Parts on their own |
| `taru_seal_qr_heartwood.svg` | Seal with the QR zone marked (dashed square) for tags |
| `taru_descriptor_{everyday,festive,ceremonial}.svg` | Wordmark with line descriptor on its line colour |
| `taru_devanagari_heartwood.svg` | तरु mark |
| `build_logo.py` | Rebuilds every file (Fraunces opsz 144 · wght 500 · SOFT 30 · WONK 0, tracking +40; Tiro Devanagari Hindi; IBM Plex Sans 500) |

Fonts: Fraunces, IBM Plex Sans/Mono/Sans Devanagari and Tiro Devanagari Hindi, all SIL Open Font Licence (Google Fonts).
