## Storefront images (author-supplied, 2 Oct 2026)

`storefront_collage_1` to `_4` are AI-generated collages supplied by the author for the app's storefront mock-up. The app uses 20 crops of them (`app/static/storefront/`), each labelled "AI-generated image".

| Review point | Decision |
|---|---|
| Text baked into the images | Cropped out wherever it makes a claim the claims matrix does not allow: "every stage is certified and traceable" (rings panel, CL11 Conditional), "Certified organic cotton … GOTS Licence No." (phone screen, CL01/CL13), box lid and card lines not in the matrix. The website's own text uses approved claims only. |
| Casting brief (age 40–65, fuller build in every three images, unlightened skin) | Age met in the two images with people; **no fuller build shown**, the same drift AI6 measured. Fit section should use real photography. |
| Range colours | Rust and deep maroon were not available, so the range shows sage, bottle green and navy instead; ceremonial sets are shown without the Nehru jacket. |
| QR code on the tag | Not functional; illustration only. |
| Use | Concept and mood images only, never as photographs of a real garment (AI6, D7 CL18). |
